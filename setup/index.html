TEMAzon One-time setup

1 · Sign in

Sign in as the ArcGIS Online user who should own the new feature services (a Property Officer or GIS admin with publisher rights).

Redirect URI this page uses:

2 · Create the feature services

This creates two hosted services in your ArcGIS Online content and loads the spreadsheet items:

  • Inventory service — Items and Transactions tables (Property Officer only)
  • Requests service — Requests and RequestLines tables (employees add to this)

    3 · Save the settings

    Download the updated shared/config.js and replace the one in your project (it contains the new service URLs and your client ID).

    1. Open the Inventory service item: item page → Create view layer → choose Items only → name it TEMAzon_Items_Employee_View.

    2. On the view's item page: Settings → Editing → turn off editing (read-only). Then Visualization → … → Filter on the Items layer: restricted is no (field restricted, operator is, value no) and save.
      3. 
        
    3. Share the view with everyone who should use the request form. Share the Inventory service itself only with the Property Officer(s). Share the Requests service with employees and enable editing.
